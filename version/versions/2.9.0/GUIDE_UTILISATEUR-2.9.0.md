# Guide Utilisateur 2.9.0

## Objet

L'application permet de gerer :

- les dossiers d'attribution
- la signature de remise
- la validation RGPD
- la restitution des ressources materielles
- la signature distante de remise et de restitution
- l'administration des comptes, services et ressources

## Administration

L'administration est decoupee en :

- `admin.html`
- `admin-comptes.html`
- `admin-services.html`
- `admin-ressources.html`

## Services

La liste des services proposes dans les formulaires est maintenant administrable depuis `admin-services.html`.

## Documentation

Les versions documentaires sont archivees dans `version/versions/`.
