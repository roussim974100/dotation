# Archives documentaires

Ce dossier centralise les archives documentaires versionnees du projet.

## Convention retenue

- un dossier par version : `version/versions/<version>/`
- des fichiers Markdown suffixes par la version
- un fichier `VERSION-<version>.md` dans chaque dossier pour la cartouche de tracabilite

## Nature des archives

- `snapshot courant` : copie documentaire correspondant a l'etat courant de l'application au moment de l'archivage
- `archive reconstituee` : archive documentaire reconstruite a partir de l'etat courant, des cartouches de version et de l'historique fonctionnel connu
