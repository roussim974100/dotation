# Guide Utilisateur 2.8.0

## Nouveaute principale

Un gestionnaire peut generer un lien unique de signature de remise depuis la fiche dossier.

## Usage

1. Ouvrir un dossier
2. Cliquer sur `Generer un lien de signature`
3. Copier le lien
4. Le transmettre a la personne concernee

## Cote signataire

La personne peut :

- consulter les ressources remises
- lire le RGPD
- signer sans se connecter

Le lien devient inutilisable apres validation.
