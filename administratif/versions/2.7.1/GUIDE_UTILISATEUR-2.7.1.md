# Guide Utilisateur 2.7.1

## Objet

Cette version permet de gerer :

- les dossiers d'attribution
- la signature de remise
- la validation RGPD
- la restitution des ressources materielles
- l'export PDF
- l'administration des comptes et ressources

## Parcours principal

1. Se connecter
2. Cliquer sur `Nouveau dossier`
3. Renseigner l'identite et les ressources
4. Signer et valider le RGPD si besoin
5. Cliquer sur `Enregistrer`

## Restitution

La restitution permet :

- de definir l'etat de chaque materiel
- d'ajouter un commentaire si necessaire
- de saisir une signature ou un motif
- d'exporter un `PDF restitution`

## Groupe lecture

Le groupe `lecture` peut :

- consulter les dossiers
- exporter les PDF

Le groupe `lecture` ne peut pas :

- creer
- modifier
- restituer
- supprimer
- administrer
