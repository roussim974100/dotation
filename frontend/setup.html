Contact support

La personne ou le service à contacter en cas de difficulté avec l'application. Ces informations apparaissent dans le pied de page et la page contact.

Étape 4 / 5

Types de bénéficiaires

Confirmez les types de bénéficiaires qui seront proposés dans le formulaire de dossier.

Note : Le premier type sera sélectionné par défaut dans le formulaire. Si votre organisation est une collectivité, le second type affichera un champ "Mandat" supplémentaire.

Pour modifier ces types, revenez à l'étape 1 ou modifiez-les ultérieurement dans Administration → Personnalisation.
