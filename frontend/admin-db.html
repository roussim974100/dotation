Sauvegarde

Exporter toutes les bases

Télécharge une archive unique contenant les dossiers, ressources et paramètres et les comptes et groupes. Chaque base est copiée de façon cohérente, même pendant l'utilisation de l'application.

    Minimum 8 caractères. Ce mot de passe n'est pas récupérable : sans lui, l'archive est illisible. Conservez-le dans un gestionnaire de mots de passe.

    Restauration

    Analyser puis restaurer une sauvegarde

    Le fichier est d'abord analysé (intégrité, tables, empreintes). Vous choisissez ensuite les bases à restaurer. Une copie de sécurité de chaque base remplacée est créée automatiquement.

    Bases à restaurer
    Les données actuelles des bases cochées seront remplacées. Si les comptes sont restaurés, votre session peut être invalidée : reconnectez-vous.

    Envoi

    Destinations de sauvegarde

    Envoyez une sauvegarde vers un partage réseau (SMB, NFS) ou un dossier. Le partage doit être monté sur le serveur : l'application ne stocke aucun identifiant de partage.

    Linux : montez le partage (fstab, cifs ou nfs) puis indiquez son point de montage, par exemple /mnt/sauvegardes. Windows : chemin UNC, par exemple \\serveur\partage\aquai. Le dossier doit être en dehors de l'application.

    Remplacement
    
            
    Importer une base de données
    
            
    Remplace la base courante par le fichier importé. Un backup automatique est créé avant l'opération. Le diagnostic est effectué automatiquement — l'import est bloqué si le fichier est invalide.
    
          
    
        
    
        
    
          Cette opération remplace toutes les données actuelles. Elle est irréversible (sauf restauration manuelle du backup).
