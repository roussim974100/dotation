Base de données

Gestion de la base

Exportez la base pour la sauvegarder ou la migrer. Importez une base après diagnostic pour remplacer les données courantes.

Sauvegarde

Exporter la base de données

Télécharge un fichier .db contenant l'intégralité des données (dossiers, utilisateurs, paramètres).

Télécharger la base (.db)

Vérification

Diagnostiquer un fichier

Analysez un fichier .db avant de l'importer. Le diagnostic vérifie l'intégrité, les tables et les colonnes critiques.

Remplacement

Importer une base de données

Remplace la base courante par le fichier importé. Un backup automatique est créé avant l'opération. Le diagnostic est effectué automatiquement — l'import est bloqué si le fichier est invalide.

Cette opération remplace toutes les données actuelles. Elle est irréversible (sauf restauration manuelle du backup).
